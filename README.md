# 🚀 Overview

The **17-Servo Humanoid Robot** is a DIY humanoid robotics project built to explore:

- Servo motor control
- Humanoid mechanical movement
- Embedded electronics
- Wireless communication
- Flex-sensor control
- ESP32 and ESP8266 programming
- Custom 3D-printed mechanical design

The robot uses an **ESP32-based receiver system** to control its servos and electronics, while an **ESP8266-based hand controller** uses a flex sensor to send movement commands wirelessly.

This repository contains the **source code, circuit diagrams, robot photographs, mechanical design files, and project documentation**.

# 🔩 Hardware

## 🤖 Robot Hardware

The robot consists of:

- ESP32 development board
- PCA9685 servo driver
- 17 servo motors
- OLED display
- Audio amplifier
- Speaker
- Servo power supply
- Wiring and connectors
- Custom 3D-printed mechanical structure

## 🎮 Hand Controller Hardware

The wireless hand controller consists of:

- ESP8266 development board
- Flex sensor
- Supporting components
- Power supply
- Control wiring
