# 🚀 Overview

The **17-Servo Humanoid Robot** is a DIY humanoid robotics project developed to explore humanoid movement, servo control, embedded electronics, wireless communication, and sensor-based control.

The robot uses an **ESP32-based receiver** to control the robot's servo motors and electronics.

A separate **ESP8266-based hand controller** uses a flex sensor to provide wireless control commands to the robot.

This repository contains the project's:

- Source code
- Circuit diagrams
- Robot photographs
- Mechanical design files
- Receiver and transmitter documentation
- Build information
- Project resources

The goal is to provide a clear and useful reference for anyone interested in understanding, building, modifying, or extending the robot.

# 🔩 Hardware

## 🤖 Robot Hardware

The robot receiver system includes:

- ESP32 development board
- PCA9685 servo driver
- 17 servo motors
- OLED display
- Audio amplifier
- Speaker
- Servo power supply
- Wiring and connectors
- Custom 3D-printed mechanical parts

## 🎮 Hand Controller Hardware

The wireless hand controller includes:

- ESP8266 development board
- Flex sensor
- Supporting components
- Power supply
- Connecting wires
